###  -Leevi parkkinen-

#### Git on versiohallinta ohjelma mitä käytetään tiedostojen versioitten hallintaan ja tallentamiseen

Gitin käytössä kannatta muistaa seuraavat komennot:
-
##### git status
##### git commit
##### git add
##### git branch
##### git log

#

Eniten Gitissä käytetään komentoja git add ja git commit.
-
git add lisää tiedostosi ja commit tallentaa muutokset
#

git log on tärkeä kun tekee tallennuksilla asioita
-
git log antaa sinun tallennuksista tiedoa niinkuin muutoksesi ID sarja
#
git status näyttää sinulle tiedostot jotka pitää lisätä
-
git status näyttää sinulle että mitä tiedostoja ei ole vielä lisätty tallennukseen.
